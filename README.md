# RAIR — access point

This repository serves one page: the current public URL of the RAIR review
system.

The system is exposed through a Cloudflare quick tunnel, which is assigned a new
random hostname every time the tunnel restarts. This page is updated
automatically whenever that happens, so the address here is always the live one.

**Page:** https://mkboch.github.io/rair-access/

Nothing else is stored here. The system itself, its evaluation data and its
report are not part of this repository.
